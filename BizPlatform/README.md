# BizPlatform – ניהול מלאי, חשבוניות, הכנסות, עובדים וציוד

פלטפורמה אחת בעברית (RTL) שמחברת את כל התפעול של העסק – **בחינם, בקוד פתוח, אצלך בשרת**.

| מודול | מה יש |
|---|---|
| **לוח בקרה** | הכנסות החודש/השנה, גרף 12 חודשים (חויב מול נגבה), חובות ובאיחור, שווי מלאי, מלאי נמוך, אחריות ורישיונות שעומדים לפוג, עובדים בתהליך עזיבה עם ציוד להחזרה |
| **מוצרים ומלאי** | קטלוג (מק"ט, ברקוד, קטגוריה, מחירים, ספק), ריבוי מחסנים, קליטה / הוצאה / העברה / תיקון ספירה / החזרה, חסימת מלאי שלילי, התראת מינימום |
| **מעקב חשבוניות** | רישום חשבוניות שהופקו בהנהלת החשבונות, מע"מ אוטומטי, תאריך פירעון לפי תנאי הלקוח, תשלומים חלקיים, סטטוס אוטומטי, זיהוי איחורים, **התראה על חשבונית מעל 5,000 ₪ ללא מספר הקצאה** |
| **לקוחות וספקים** | כרטיסים, ח.פ, אנשי קשר, תנאי תשלום |
| **עובדים** | כרטיס עובד, מחלקות, ת.ז מוצפנת, **תהליך עזיבה** – לא ניתן לסיים העסקה כל עוד יש ציוד בידי העובד |
| **מחשבים וציוד** | מחשבים, מסכים, טלפונים, רישיונות תוכנה – מספר סידורי, מפרט, אחריות, מסירה/החזרה עם מצב הפריט וחתימת עובד, היסטוריית החזקה מלאה, מפתחות רישיון מוצפנים |
| **ניהול** | משתמשים ו-7 תפקידים, אימות דו-שלבי, יומן ביקורת חסין-שינויים, ייצוא ל-Excel |

## התקנה (שרת / מחשב במשרד / ענן חינמי)
דרישות: Linux (או Windows/Mac עם Docker Desktop) + Docker.
```bash
git clone <repo> bizplatform && cd bizplatform
./scripts/setup.sh                 # יוצר .env עם סודות אקראיים חזקים
docker compose up -d --build
docker compose exec backend python -m app.cli create-admin --email you@company.co.il --name "השם שלך"
```
פתח בדפדפן `https://<הדומיין>` (או `https://localhost` / כתובת ה-IP של השרת ברשת המשרד).
בכניסה הראשונה המערכת תבקש להגדיר אימות דו-שלבי.

**אפשרויות אחסון חינמיות:** מחשב/שרת קיים במשרד · Oracle Cloud Free Tier (4 ליבות ARM, 24GB RAM – חינם לתמיד) · כל VPS זול.
בשרת ציבורי: הפנה רשומת DNS לשרת, הזן את הדומיין ב-`setup.sh` – תעודת HTTPS תונפק אוטומטית בחינם.

## גיבוי ושחזור
גיבוי מוצפן נוצר אוטומטית כל 24 שעות בתיקייה `backups/` (נשמר 30 יום).
שחזור: `./scripts/restore.sh backups/bizplatform-YYYYMMDD-HHMMSS.sql.gz.enc`
**העתק את תיקיית הגיבויים גם למקום נוסף.**

## פיתוח
```bash
# backend
cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp ../.env.example .env   # ערוך: BIZ_ENV=development, BIZ_COOKIE_SECURE=false, BIZ_ENCRYPTION_KEY=<Fernet key>
.venv/bin/python -m app.cli create-admin --email admin@example.com --name Admin
.venv/bin/python -m app.cli seed-demo     # נתוני דמו
.venv/bin/uvicorn app.main:app --reload
.venv/bin/pytest                           # 23 בדיקות אבטחה ולוגיקה
# frontend
cd frontend && npm install && npm run dev  # http://localhost:5173
```
מבנה: `backend/` FastAPI + SQLAlchemy + PostgreSQL · `frontend/` React + Vite · `docker-compose.yml` + Caddy (HTTPS).
